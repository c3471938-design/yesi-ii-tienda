# YESI II · Tienda

Sitio estático adaptable a celular con catálogo, búsqueda, fichas y carrito persistente.

## Publicación
GitHub Pages: rama main, carpeta raíz. No requiere instalación ni compilación.

## Archivos
index.html, blue-studio.css, blue-studio.js, config.js y assets/.

## Agregar productos
Consultar AMPLIAR-CATALOGO.md. Los precios y los productos adicionales se configuran en config.js.

## Estado comercial
Los precios, contacto y cobro real están pendientes. El carrito permite descargar solicitudes; no realiza pagos ni envía pedidos automáticamente.
